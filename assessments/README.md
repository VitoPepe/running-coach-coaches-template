# Évaluations (assessments)

> **À quoi sert ce fichier :** tes protocoles de tests et grilles d'interprétation.
> **Mis à jour par :** le coach.

Protocoles de tests et grilles d'interprétation. Un fichier par test
(ex. `vma-demi-cooper.md`, `ftp-20min.md`, `css-400-200.md`, `test-lactate.md`).
Les résultats vont dans `athletes/<slug>/tests.md`.

Structure d'un fichier de test :
- Objectif / ce qu'il mesure
- Prérequis (forme, échauffement, terrain, matériel)
- Protocole pas à pas
- Calcul des repères et des zones (lien `coach/philosophy/intensites-zones.md`)
- Fréquence recommandée
- Limites / pièges d'interprétation

## Suivre la progression
- [`progress-indicators.md`](progress-indicators.md) : quels indicateurs croiser pour savoir si
  un athlète progresse d'une saison à l'autre (courses, entraînement, contexte).
