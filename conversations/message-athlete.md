# Message à un athlète — un brouillon dans ton ton

> **À quoi sert ce fichier :** préparer un message pour un athlète (retour de séance, bilan de semaine, encouragement, recadrage) que le coach relit et envoie lui-même.
> **Mis à jour par :** contenu du projet.

**Comment le lancer** : « Prépare un message pour Julie sur sa semaine », « Un mot d'encouragement pour Marc avant samedi ».

---

1. Lis `coach/philosophie/communication.md` : c'est la règle de ton, de longueur et de contenu.
2. Lis le profil de l'athlète (« Préférences de communication », points de vigilance) et les 5 dernières lignes de son journal.
3. Récupère dans Nolio les faits utiles (séances, commentaires) sur la période concernée.
4. Écris le brouillon :
   - le ton et le tutoiement ou vouvoiement du coach ;
   - des faits précis (séance, date, chiffre), jamais de comparaison avec un autre athlète ;
   - un point positif d'abord, puis un point à travailler au plus, puis la suite ;
   - aucun conseil de perte de poids ni de restriction ;
   - un drapeau rouge de santé n'est pas traité par message : propose au coach d'appeler.
5. Donne le brouillon dans un bloc facile à copier, et demande : « Je le note dans son journal une fois envoyé ? ».

**Tu n'envoies jamais rien toi-même**, même si un connecteur de messagerie est branché.
