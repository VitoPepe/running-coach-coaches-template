# Communication avec les athlètes

> **À quoi sert ce fichier :** exemple fictif — le ton et le format des messages de Hugo à ses athlètes. Tous les brouillons de l'agent le suivent.
> **Mis à jour par :** la conversation d'arrivée (bloc 2), puis le coach (ici : écrit pour l'exemple).

- Tutoiement / vouvoiement : tutoiement, toujours.
- Ton (direct, bienveillant, technique…) : direct et chaleureux. Je dis les choses franchement, sans dramatiser. Je parle de sensations avant de parler de chiffres, sauf avec ceux qui aiment les chiffres (c'est noté dans leur profil).
- Longueur type d'un retour de séance : 3 lignes au plus. Un fait, ce que ça veut dire, la suite.
- Ce que je mets toujours dans un bilan hebdo : un point positif précis (une séance, un chiffre), un seul point à travailler, la semaine suivante en une phrase, une question ouverte.
- Ce que j'évite (ex. comparer aux autres athlètes, parler poids sans demande…) : comparer à un autre athlète ; parler poids ou régime ; le jargon avec les débutants (« facile » plutôt que « Z2 ») ; commenter un footing conforme ; plus d'un point d'exclamation et plus d'un emoji par message ; traiter une douleur par écrit : j'appelle.

## Exemples de messages que j'aime
> Belle séance de seuil : 3 blocs réguliers, et le dernier aussi propre que le premier. C'est exactement ce qu'on cherche en ce moment. Demain footing vraiment facile, tu l'as mérité.

> Pas de souci pour la séance sautée, ça arrive. Dis-moi juste si c'est la fatigue ou l'agenda, que j'ajuste la semaine.
